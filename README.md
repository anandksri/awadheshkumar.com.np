# Awadhesh Kumar — Personal Website

This repository contains the source code for the Awadhesh Kumar personal website.

## About

The project is a modern web application built to present personal, professional, and portfolio information through a responsive interface.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express
- Google GenAI
- Motion
- Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anandksri/awadheshkumar.com.np.git
cd awadheshkumar.com.np
```

Install dependencies:

```bash
npm install
```

Configure required environment variables locally. Never commit API keys, credentials, or production secrets.

Run the development server:

```bash
npm run dev
```

The development server is configured to run on port `3000`.

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run clean
```

## Deployment

Create a production build with:

```bash
npm run build
```

The generated `dist` directory can then be deployed using a suitable static hosting platform or served through the project's deployment setup.

## Security

Environment-specific configuration should remain outside version control. Review third-party API usage and server-side configuration before deploying the application publicly.
